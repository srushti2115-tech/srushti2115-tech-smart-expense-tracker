# Smart Expense Tracker & Financial Analytics App

A production-ready Flutter mobile application for tracking expenses, managing budgets, analyzing spending patterns, and generating smart financial insights using Firebase.

This project is designed as a real-world, multi-user system suitable for internships, placements, and practical deployment.

---

## Overview

The Smart Expense Tracker application helps users monitor their daily expenses, plan budgets, and gain insights into their financial behavior through analytics and intelligent recommendations. The app supports secure authentication, cloud synchronization, and advanced analytics.

---

## Features

### Authentication
- Email and password login
- Google Sign-In
- Forgot password via email reset
- Secure multi-user access with per-user data isolation

### Expense Management
- Add, edit, and delete expenses
- Categorized expenses (Food, Travel, Rent, Shopping, etc.)
- Date-wise expense tracking
- Transaction history

### Analytics and Dashboard
- Total expense summary
- Category-wise pie chart visualization
- Monthly expense analysis
- Clean and responsive dashboard layout

### Budget Management
- Set category-wise budgets
- Overspending alerts
- Real-time budget monitoring

### Smart Insights
- Spending pattern analysis
- Monthly expense prediction
- Smart savings recommendations
- Unusual expense detection

### Data Export and Backup
- Export expenses to CSV format
- Generate PDF expense reports
- Cloud backup using Firebase Firestore

### Notifications
- Budget overspending alerts
- Local notifications support

### User Interface
- Clean and modern UI
- Light and dark mode support
- Bottom navigation structure
- Category-based colors and icons

---

## Technology Stack

| Layer | Technology |
|------|-----------|
| Mobile App | Flutter (Dart) |
| Backend | Firebase |
| Authentication | Firebase Authentication |
| Database | Cloud Firestore |
| Notifications | Firebase Cloud Messaging, Local Notifications |
| Charts | Flutter chart libraries |
